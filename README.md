# Glyphotrame

Application de bureau qui transforme des images en trames graphiques : caractères du clavier ou halftone (points, lignes, pointillisme, CMJN), avec dégradés, détourage, effets néon et exports PNG, JPEG, SVG et HTML.

Construite avec Tauri 2, React et Vite.

- Pour commencer : **[DEMARRAGE.md](DEMARRAGE.md)**
- Brief technique (lu par Claude Code) : [CLAUDE.md](CLAUDE.md)
- Fonctionnalités : [docs/fonctionnalites.md](docs/fonctionnalites.md)
- Version de référence (un seul fichier HTML) : [reference/glyphotrame-reference.html](reference/glyphotrame-reference.html)

```powershell
npm install
npm run tauri dev     # développement
npm run tauri build   # installateur
```
