Forme de la frontière

Dessine sur l'aperçu avec la barre d'outils Plume qui s'affiche au-dessus de l'image, comme dans Photoshop. Un tracé fermé entoure un élément : l'effet s'applique à l'intérieur. Un tracé ouvert coupe l'image : l'effet va du côté gauche du tracé. « Inverser les côtés » fait l'inverse.

Raccourcis clavier
  • P Plume · A Sélection directe · + Ajouter · − Supprimer · Maj+C Convertir
  • Plume : clic = point d'angle, cliquer-glisser = point courbe. Clic sur le premier point = fermer. Survol du tracé = ajouter, survol d'un point = supprimer.
  • Alt en glissant une poignée : casse la symétrie (point d'angle courbé).
  • Maj : contraint à 45°. Suppr retire le point sélectionné. Échap arrête le tracé. Ctrl+Z / Ctrl+Maj+Z annuler / rétablir.
Côté de l'effet

La flèche indique où l'effet est le plus fort. L'autre côté garde l'image d'origine. Le centre crée un dégradé rond.

Courbe de progression

Hauteur = intensité de l'effet. Glisse les deux poignées pour régler la vitesse du fondu.

Grille

En CMJN, chaque encre a son propre angle (cyan 15°, magenta 75°, jaune 0°, noir 45°), ajouté à l'angle de la trame. C'est ce qui crée la rosette des impressions offset.

Couleurs

Palette néon

0 % = palette seule, 100 % = vraies couleurs de l'image passées en néon. Entre les deux, les deux se mélangent.

Les zones sombres prennent la couleur des ombres, les plus claires celle des lumières. Sur fond sombre, l'effet ressort comme un écran allumé.

Néon & écran

Fond noir, palette violet / jaune, lueur et grille d'écran. Tous les réglages restent modifiables ensuite.

Sortie

Le SVG et le code restent vectoriels : ils s'affichent nets à toutes les tailles.
